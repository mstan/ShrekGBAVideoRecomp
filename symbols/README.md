# Symbols and annotations

Shrek Movie has no public matching decompilation or symbol set integrated yet.
The initial build uses conservative recursive control-flow discovery from the
retail entry point. Reviewed function boundaries, jump tables, copied-code
ranges, and names belong in this directory as they are recovered.

Do not commit a Ghidra project. Export human-authored annotations to
`ghidra/annotations/*.annotations.json` when a registry project is available.
